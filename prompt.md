Agent Mission Execution Strategy
You should follow these steps:
-Enter and Analyze the Minecraft World
    The agent enters the Minecraft world and analyzes its environment.
    It identifies the terrain type, surrounding landscape, and available resources.
-Find Mission-Required Animals
    The agent searches for animals required by the mission, such as pigs, chickens, cows, sheep, rabbits, etc.
-Collect Necessary Food
    While searching for animals, the agent collects the appropriate food needed to attract and breed them.
-Feed Animals to Accelerate Their Growth
    The agent feeds animals with the appropriate food to accelerate their growth.
    It estimates how much time each animal needs to reach adulthood.
-Optimize Feeding Based on Remaining Time
    If an animal can become an adult through natural growth within the remaining mission time, the agent should avoid feeding it unnecessarily.
    Instead, it should reserve food for animals that need accelerated growth.
-Prioritize Breeding to Complete the Mission
    The agent should make every possible effort to complete the mission using available food and remaining time.
    If there is insufficient time to complete the mission through normal growth and breeding, the agent should determine which animals should be prioritized for breeding to maximize the probability of success.
-Optimize All Actions
    The agent should continuously evaluate the current situation, available resources, animal growth times, and remaining mission time.
    It should select the most efficient actions and dynamically adjust its strategy to maximize the probability of completing the mission before the deadline.
